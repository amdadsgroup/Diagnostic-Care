# Diagnostic Care — Agent Directives & Workflow Rules

## Mandatory Code Update & Synchronization Policy
- **Always Update GitHub After Changes**: Whenever code is edited, created, or updated in this repository, always run validation (e.g. `npx tsc --noEmit` or build check) and then commit and push the changes directly to GitHub (`origin/main`).
- Never leave finished code modifications unpushed without informing and synchronizing with GitHub.
- Use clean, conventional commit messages (e.g., `feat: ...`, `fix: ...`, `refactor: ...`).
